# Nest 0.1.0 — prerelease notes

## Purpose

Nest brings everyday spending, budgets, credit cards, reimbursements, savings, investments, and household planning into one personal finance workspace. This initial preview focuses on understanding where money is, what it is allocated to, and what is still owed.

## Scope

- **Snapshot date:** October 6, 2026.
- **Package version:** `0.1.0`.
- **Source:** `main` at [`c865f3e`](https://github.com/peternoobmaster69/Nest/commit/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5), including the contact-form change.
- **Release status:** draft notes; a prerelease tag has not been assigned. This is an initial feature snapshot, with no earlier tagged release to compare against.
- **Website:** [save.htet.info](https://save.htet.info).

## Included features

- **[Accounts and transactions](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/ledger.md):** track bank control balances, divide money into virtual sub-accounts, record income and expenses, transfer allocations, and organize transactions into groups.
- **[Monthly budgeting](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/budgets.md):** maintain reusable income and budget templates, prepare individual monthly plans, and confirm balanced plans to fund linked sub-accounts.
- **[Credit cards](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/cards.md) and [receivables](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/receivables.md):** manage statement cycles, due dates, purchases, refunds, payments, accounting rules, and reimbursements. Closing a receivable creates linked settlement transactions.
- **[Savings and investments](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/investments.md):** identify savings sub-accounts, record dated investment valuations and cumulative contributions, track liquid holdings, and compare gains with all-time or annualized money-weighted returns (XIRR).
- **[Nest CIO](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/cio.md):** configure individual or household planning assumptions, asset exposure and allocation policies, recurring contributions, liquidity targets, and retirement scenarios. Save strategy-report snapshots and download them as PDFs.
- **[Rewards](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/rewards.md):** track frequent-flyer miles, expiry lots, redemptions, hotel points, credit-card rewards, and points-to-miles conversions.
- **[Shared workspaces](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/workspaces.md):** invite collaborators, manage access through owner/editor/viewer roles, use workspace-specific URLs, and follow an onboarding guide. Owners can enable, rotate, or revoke public links for aggregate net-worth data.
- **[Ask Nest and Smart Review](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/ai.md):** ask questions grounded in workspace records and review suggested card-accounting actions. The [transaction assistant](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/transaction-agent.md) prepares income, expense, or correction drafts; an editor must review and press Confirm before a draft changes financial records. Administrators can configure the three agents and their capabilities.
- **[Web and device experience](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/web-ui.md):** use responsive layouts, install Nest as a PWA, manage passkeys and active sessions, and receive in-app notifications. Provider sign-in, email, and push features depend on deployment configuration.

## Recent improvements

- **Corrected card amounts due:** statement balances include all associated refunds and payments before applying due-date filters, preventing paid or reduced statements from producing overstated reminders.
- **Improved mobile presentation:** updated application icons, iOS standalone viewport sizing and header behavior, keyboard-focus visibility for the skip link, and account, sub-account, and investment card layouts.
- **Persistent Ask Nest conversations:** minimize chat to the Nestling launcher while an answer continues, then return to it across in-app navigation.
- **Investment return views:** switch between all-time returns and annualized XIRR, which accounts for the timing of recorded contributions and withdrawals. Annualized returns are unavailable when the recorded history is insufficient.
- **Public-site SEO:** added canonical URLs, page metadata, social previews, structured data, `robots.txt`, and a sitemap for public pages. Private workspace pages, authentication variants, and API responses carry `noindex` directives.
- **Contact form:** visitors can send general questions, hosting requests, feedback, and bug reports from the landing page. Delivery uses the configured administrator inbox, with validation and rate limits.

## Dependencies

Self-hosting requires **Node.js 22.13 or newer, npm, and SQL Server or Azure SQL**. The application uses Next.js, React, TypeScript, Tailwind CSS, Prisma, and NextAuth.

| Capability | Configuration needed |
| --- | --- |
| Google, Apple, or Facebook sign-in; passkeys | Credentials for enabled OAuth providers; matching passkey origin and relying-party settings |
| Gmail card-alert ingestion | Google OAuth and encrypted token storage; scheduled jobs for automatic synchronization |
| Ask Nest, transaction interpretation, and Smart Review | Azure AI workload endpoint, API key, and model deployment; some simple transaction commands have a local parsing fallback |
| Optional research and knowledge search | Separately configured market/news providers, public research providers, or Azure AI Search |
| Contact messages and email reminders | Azure Communication Services email credentials and sender; contact delivery also requires `ADMIN` |
| Push and scheduled reminders | VAPID configuration, user opt-in, and authenticated scheduled jobs |

See [`.env.example`](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/.env.example) for configuration and [the integration guide](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/modules/integrations.md) for supported Gmail alerts and CSV imports.

## Installation and upgrades

Follow [the setup instructions](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/README.md#getting-started) and [database operations runbook](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/database/operations.md).

1. Install dependencies with `npm ci` and configure the database, application URL, authentication, and required secrets.
2. For a **new empty database**, use `npm run db:bootstrap`. For an existing installation, back up the database and apply forward migrations with `npm run prisma:migrate:deploy`.
3. Generate Prisma with `npm run prisma:generate`, build with `npm run build`, and deploy code and migrations from the same snapshot.
4. Configure the callbacks and scheduled jobs for enabled integrations using [the deployment guide](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/docs/guides/deployment.md).

## Assumptions

Features above describe the checked-in implementation. Their availability in a particular deployment depends on its applied migrations, configuration, provider access, and user permissions. These notes do not establish which optional integrations are currently enabled in production.

## Known Limitations

- **Manual reconciliation:** transactions update sub-account balances; configured bank balances must be refreshed separately. Investment valuations also require updates. Nest has no general bank feed or automatic valuation of owned investments.
- **Currency and net worth:** the workspace currency controls presentation without automatic foreign-exchange conversion. Dashboard and public net worth mean savings sub-accounts plus investment values; they exclude non-savings cash allocations and do not subtract card liabilities. CIO planning has its own additional assets and liabilities.
- **Receivable settlement:** a partial status exists, but Close settles the full recorded amount. Adjust or split the record to represent a partial repayment before closing it.
- **Offline use:** cached static assets support the PWA experience; financial changes are not queued for later submission while offline.
- **Assistant scope:** transaction drafts handle ordinary income, expenses, and corrections one at a time. Transfers, card payments, receivables, and deletions use their dedicated workflows. CIO projections depend on recorded data and assumptions; trade execution, tax modeling, and Monte Carlo simulation are outside this preview.
- **Search setup:** Google Search Console ownership verification and sitemap submission were still pending in the last deployment review.
- **Licensing:** the repository is publicly visible, but no open-source license has been selected. See [the licensing statement](https://github.com/peternoobmaster69/Nest/blob/c865f3e964555a0bfc36f8cb0fd295c49e9e2bc5/README.md#license).
